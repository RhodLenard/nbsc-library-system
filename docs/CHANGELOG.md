# Architecture changelog

## 2026-10-15 — MariaDB selected for v2

v2 uses MariaDB 11.4 LTS (pinned to the latest patch) instead of PostgreSQL. The supplied legacy snapshot was generated by MariaDB 10.4.32 and uses InnoDB with `utf8mb4_general_ci` / `utf8mb4_unicode_ci`; MariaDB preserves the source dialect and lowers import risk. The new v2 schema standardizes canonical fields on `utf8mb4_unicode_ci` while preserving legacy values and their `utf8mb4_general_ci` comparison behavior for traceability.

Prisma ORM 7 uses the `mysql` provider for MariaDB. Prisma ORM 8 is deferred because it does not currently support MariaDB.
